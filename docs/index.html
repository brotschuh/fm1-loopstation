FM-1 Loop Station

Drei Loop-Spuren aus dem Mikrofon, eine Drum-Spur mit echtem Rock-Kit und 808-Kit, Effekte. Bedient wird am FM-1 wie an einem Loop-Pedal, das Handy ist der grosse Bildschirm.

  1. FM-1 mit der Loop-Station-Firmware per USB-C anschliessen.
  2. Kopfhoerer oder Box ans FM-1.
  3. Starten tippen und Mikrofon und MIDI erlauben.

EINSTELLUNGEN

BEDIENUNG AM FM-1

RECAufnahme → Overdub → Wiedergabe → Overdub … (wie am Loop-Pedal). Auf der Drum-Spur: Pads ins Muster einspielen.
PLAYAlles starten / stoppen
SCLUndo / Redo der letzten Aufnahme
HOMETippen: Hauptseite (SELECT waehlt die Spur). Halten: gewaehlte Spur stumm / an
SAVE haltenGewaehlte Spur loeschen
ARPTippen: Drums an / aus. Halten: Klick an / aus (nur im Kopfhoerer, nie in der Aufnahme)
SELECTSpur waehlen (1, 2, 3, Drums)
PRESETSDrum-Muster waehlen
ALGORITHMDrum-Instrument fuer die Schritt-Tasten waehlen
FXEffekte der gewaehlten Spur: DELAY, REVERB, CHORUS, BITCRUSH. Mit SELECT (oder FX nochmal) blaettern, K1–K4 stellen die Werte.
ENV · EDIT · GLO · SEQSeiten FILTER · SPUR · MIKRO (auf dem Handy bei den Einstellungen) · DRUMS
LFOTippen: Seite STUTTER. Halten: Stutter
Tasten 1–16Die 16 Schritte des gewaehlten Drum-Instruments (leuchtet = Schlag)
Tasten 17–27Drum-Pads: Kick, Snare, Rimshot/Clap, Hat zu, Hat auf, 3 Toms, Sidestick/Rim, Ride/Cowbell, Crash/Becken
TastenlichtSeite MIKRO (GLO), K4: Grundhelligkeit der Tasten von AUS bis 8; die aktive Taste leuchtet voll (braucht die Loop-Station-Firmware).

Am Computer ohne FM-1: Leertaste = Play, R = Rec, Z = Undo, 1–4 = Spur, S halten = Stutter, K = Klick.
