RECAufnahme → Overdub → Wiedergabe → Overdub … (wie Boss). Auf der Drum-Spur: Pads ins Muster einspielen.
PLAYAlles starten / stoppen
SCLUndo / Redo der letzten Aufnahme
HOMEGewaehlte Spur stumm / an
SAVE haltenGewaehlte Spur loeschen
ARPDrums an / aus
SELECTSpur waehlen (1, 2, 3, Drums)
ALGORITHMDrum-Muster waehlen
PRESETSDrum-Instrument fuer die Schritt-Tasten waehlen
FX · ENV · EDIT · GLO · SEQSeiten DELAY+HALL · FILTER+BITCRUSH · SPUR · MIKRO · DRUMS. K1–K4 stellen die vier Werte. Bitcrusher: ENV, dann K3 (Bits) und K4 (Samplerate).
LFOTippen: Seite CHORUS+STUTTER. Halten: Stutter
Tasten 1–16Die 16 Schritte des gewaehlten Drum-Instruments (leuchtet = Schlag)
Tasten 17–27Drum-Pads: Kick, Snare, Rimshot/Clap, Hat zu, Hat auf, 3 Toms, Sidestick/Rim, Ride/Cowbell, Crash/Becken
TastenlichtSeite MIKRO (GLO), K4: IMMER AN = alle Tasten leuchten, aktive blinken. STATUS = nur aktive leuchten.

Am Computer ohne FM-1: Leertaste = Play, R = Rec, Z = Undo, 1–4 = Spur, S halten = Stutter.
